# Fonts

Font binaries are intentionally excluded from the public Git repository until their redistribution licenses have been reviewed.

The overlays reference filenames such as:

- `Replica-Bold.ttf`
- `FoundryGridnik-ExtraBold.ttf`
- `FoundryGridnikW03-ExtraBold.ttf`
- `Tungsten-Bold.ttf`
- `LINESeedTW_TTF.ttf`

Operators must provide legally licensed copies under `public/assets/fonts/`, or update the CSS to use fonts they are permitted to redistribute. Possession of a font file does not necessarily grant redistribution rights.
