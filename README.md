# PulseVeto

PulseVeto 是為 VALORANT 賽事設計的地圖 Ban／Pick、攻守選擇、比分管理與轉播輔助服務，讓賽事單位、對戰隊伍與觀眾掌握同一場比賽的進度。

- [前往 PulseVeto](https://veto.pulse-studio.live)
- [閱讀公開文件](https://veto.pulse-studio.live/docs)（開放準備中）

本 repository 公開專案原始碼。使用服務請透過官方網站及賽事單位提供的入口；本頁不提供本地部署教學或自架服務支援。各項功能的實際開放狀態，以線上服務與公開文件為準。

## 賽事單位可以做什麼？

### 管理賽事與對局

- 在獲授權的賽事單位範圍內，建立及管理多個賽事與單場 BP。
- 設定賽事名稱、說明、識別圖片及賽事地圖池。
- 設定對戰隊伍名稱與 Logo，分別提供雙方隊伍操作代碼。
- 在管理頁取得隊伍入口、公開結果頁與轉播連結，分別提供給選手、觀眾及轉播人員。

### 設定 BP 流程

- 使用標準 Bo1／Bo3／Bo5 流程，或建立符合賽事規章的具名自訂流程。
- 賽事地圖池可選擇 2–20 張已啟用地圖；每個流程可指定禁用、選擇、選邊隊伍及最後的 Decider。
- 建立對局時選用流程，並分別設定地圖選擇與攻守選擇時間，也可設為不限時。
- 雙方隊伍確認準備後開始 BP；隊伍頁、管理頁與轉播畫面同步顯示進度。

既有對局保留建立時的流程。修改賽事流程不會回頭改變已建立的對局；已有對局的地圖池不可直接變更，請在建立對局前確認賽事規章與設定。

### 管理比分與比賽進度

- 更新各張比賽地圖的比分與勝方。
- 標示下一張比賽地圖，讓結果頁與轉播畫面同步呈現賽事進度。
- 在管理介面查看版本更新日誌，掌握功能調整與操作變更。

## 隊伍如何操作？

1. 使用賽事單位提供的隊伍入口與操作代碼進入對局。
2. 確認隊伍與對局資訊，完成準備確認。
3. 依畫面提示進行 Ban、Pick 或攻守選擇；僅能操作輪到自己隊伍的步驟。
4. 如流程產生隨機地圖或選邊結果，依畫面提示完成確認後繼續。

系統提供同步倒數與操作紀錄。請在賽前與賽事單位確認限時及超時處理規則，並妥善保管隊伍操作代碼，勿作為觀眾分享連結公開。

## 公開結果與轉播

- **公開結果頁**：分享 BP 地圖、攻守安排與已更新的比分；觀眾不需要隊伍操作代碼。
- **分享預覽**：結果連結提供對局資訊預覽，方便在社群或通訊平台分享。
- **OBS Overlay**：提供繁體中文與英文 VCT 樣式，以及各自的一次顯示版本；另有目前地圖與結果畫面。
- **即時同步**：BP 與比分更新會反映到相關隊伍頁、結果頁及轉播畫面。
- **多語系介面**：提供繁體中文、簡體中文、English (US) 與日本語；各頁面支援範圍以介面選單為準。

轉播人員請使用管理頁產生的 Overlay 連結加入 OBS「瀏覽器來源」，畫面尺寸設為 **1920 × 1080**。隊伍操作代碼、結果連結與 Overlay 連結用途不同，請分別提供給適當人員。

## 賽事使用流程

1. 由 Pulse Studio 開通賽事單位授權，再使用獲授權帳號登入。
2. 建立賽事、設定地圖池及 BP 流程。
3. 建立對局，確認隊伍資訊與操作時間。
4. 將隊伍入口與代碼分別提供給雙方，將轉播連結交給製播人員。
5. 雙方準備完成後進行 BP，賽事單位依比賽進度更新比分，並分享公開結果頁。

操作說明將整理於[公開文件](https://veto.pulse-studio.live/docs)。文件入口目前仍在開放準備中；服務可用範圍與使用安排請依 Pulse Studio 的公告及授權資訊。
