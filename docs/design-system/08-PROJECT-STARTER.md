## 可複製的設計提示詞

```text
請為「[產品名稱]」設計並實作「[本次頁面或範圍]」。
用途是「[用途]」，主要使用者需要完成「[任務]」。
請先讀取 docs/design-system/README.md 及相關規範，
依產品設定表處理品牌、語系與特殊例外。

延續 Pulse 的清楚、精準與節奏感：以 Pulse Blue #5865F2 為主要色，
Veto Violet #8B5CF6 為輔助，少量 Cyan 點綴。
明暗主題透過語意 Token 實作。正文以系統無襯線字型和可讀行高呈現，
採 4px 間距尺度，控制項至少 44px 高，表面以細邊框與適度圓角區分。
頁面先讓人理解目的與主要操作，再提供次要資訊。
管理資料優先以列表、對齊和分隔線組織；品牌展示區可有限使用藍紫漸層。
不要添加無功能英文副標，避免多層卡片包覆與過度動效。

沿用專案技術與既有元件，不為規範新增不必要依賴。
提供載入、空白、成功、失敗、禁用與權限不足等相關狀態。
檢查手機、小型筆電、鍵盤操作、長文字、明暗主題與減少動態效果。
明確區分來源特徵、新訂預設及本次必要例外。
交付時列出實際驗證結果與未驗證項目。
```

不沿用 Pulse 品牌的新產品，先替換色彩與署名，再保留版面、排版、元件及驗收原則。不要只更改提示詞而留下矛盾的 Token 文件。

## 可加入新專案 AGENTS.md 的片段

```markdown
## 視覺設計

- UI 修改前閱讀 docs/design-system/README.md 與本次相關規範。
- 品牌、字級、間距與元件狀態沿用共用 Token。
- 明確產品需求優先；必要例外記錄於產品設定表，不擴大改動範圍。
- 不信任用戶輸入，使用安全 DOM／既有安全渲染方式。
- 實質 UI 修改需做代表性瀏覽器、console 與互動驗證。
- 保留既有工作，依本專案 Git 與部署授權規則交付。
```

這段只定義設計工作方式，不替新專案設定 Git 遠端、正式部署、服務重啟或對外傳訊授權。
