# 品牌與視覺方向

## 核心方向

延續 Pulse 的清楚、精準、穩定與節奏感。以內容和操作為主，藍紫色建立識別，留白與文字層級協助使用者快速理解。管理頁偏向安靜的工具介面；品牌展示區可增加少量光暈、網格與漸層。

來源特徵：首頁深色品牌展示搭配淺色登入區、管理介面的紫色導覽與淺色內容、操作頁的深色面板。新專案依用途選擇，不要求每一頁混合三種風格。

| 場景 | 建議表現 | 優先目標 |
| --- | --- | --- |
| 首頁／登入 | 清楚主標、有限品牌視覺、集中的操作區 | 理解產品並完成進入 |
| 管理／資料 | 平實表面、列表分隔、穩定導覽 | 找到資訊並完成工作 |
| 即時操作 | 深色可選、明確狀態與主要操作 | 迅速辨識下一步 |
| 公開結果／報告 | 清楚標題、大數值、易讀細節 | 分享與閱讀 |

## 識別規則

- 產品名稱是主要識別；沿用 Pulse 生態系時，可將 `Powered by Pulse Studio` 放在次要位置。其他品牌由新專案自行確認署名。
- 使用正式 Logo 原檔，維持長寬比，不重繪、不拉伸、不任意換色。深色／淺色背景分別檢查辨識度。
- 建議 Logo 留白至少為圖形高度的 1/4；這是本範本的排版預設，若正式品牌手冊有規定則以其為準。
- Logo 最小尺寸以實際可辨識程度確認，不把管理頁圖示尺寸當成所有商標的最小尺寸。
- 圖示採一致線條、尺寸與光學對齊；同一控制不要在各頁混用文字、emoji 與不同圖示組。

## 視覺語言

- 主要色為 Pulse Blue，Veto Violet 作為輔助識別；Cyan 用於少量點綴。
- 135° 藍紫漸層適合品牌展示或主要動作，避免套在每張卡片與每個標題。
- 一般表面使用細邊框、有限陰影、適度圓角。建議控制項 8–12px、面板 16px；大型品牌展示可採 24px。
- 背景網格與光暈降低存在感，維持正文清楚；不能用裝飾線替代資訊分組。
- 標題直接說明內容，不新增無功能的英文副標、流水編號或裝飾性標籤。
- 列表優先用間距與分隔線組織；卡片代表獨立資訊單位，避免多層卡片互相包覆。

## 素材與產品界線

新專案只攜帶可使用且授權明確的素材。建立素材紀錄，列出來源、作者、授權、用途與是否可再散布；字型亦同。不因本機有檔案就將其加入公開 repository。

PulseVeto 的 Overlay 是獨立轉播產品：保留透明合成、1920×1080 與原有視覺。這套非 Overlay 規範不授權調整它，也不把轉播字型當成一般網站預設。新專案若有類似展示介面，先另定畫布、字級、背景與播放條件。

涉及 VALORANT 的公開材料保留非 Riot Games／VALORANT 官方認可聲明；其他專案依其實際品牌與素材關係撰寫。
