# 設計與實作驗收

這是新專案的驗收清單，不是 PulseVeto 已通過的檢查紀錄。按實際範圍勾選，未執行項目記錄原因。

## 品牌與版面

- [ ] 產品名稱、Logo、署名與素材授權已確認。
- [ ] 主要色、語意色與明暗 Token 使用一致。
- [ ] 頁面目的、主要操作與文字層級清楚。
- [ ] 字級與間距依尺度，必要例外已記錄。
- [ ] 無不必要英文副標、重複卡片與無用途裝飾。
- [ ] 320px、390px、1366×768、1920×1080 代表性版面沒有內容遮蔽或非預期水平捲動。
- [ ] 長名稱、長 URL、空值、大數值與最長語系保持可讀。

## 操作與無障礙

- [ ] 主要動作、圖示按鈕及語言／主題控制都有可存取名稱。
- [ ] 鍵盤可完成導覽、表單、選單與對話框操作，焦點清楚且順序合理。
- [ ] 對話框關閉後恢復焦點，手機導覽不留下焦點陷阱。
- [ ] 表單標籤、說明與錯誤關係正確，失敗不丟失輸入。
- [ ] 狀態除顏色外有文字或其他線索。
- [ ] 一般文字對比目標至少 4.5:1；大字至少 3:1；必要控制邊界與狀態指示至少 3:1。實測包含透明與漸層背景。
- [ ] 200% 縮放仍可操作，縮窄至 320px 時一般內容可重排；資料表例外只在局部捲動。
- [ ] 減少動態效果設定有效，倒數／即時更新不反覆打斷讀屏。

以上對比與重排目標參照 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 的 1.4.3、1.4.10、1.4.11；清單不等於完整 WCAG 合規評估。

## 狀態與工程交付

- [ ] 載入、空白、成功、失敗、禁用、唯讀與權限不足已驗證。
- [ ] 重複點擊與慢速回應不造成重複提交或錯誤成功提示。
- [ ] 代表性瀏覽器無新增 console 錯誤，資源載入成功。
- [ ] 文字安全插入，不以不安全 HTML 拼接不可信內容。
- [ ] 依修改範圍完成語法、型別或相關測試；記錄實際結果。
- [ ] 文件、Token 與元件同步，沒有提交秘密、授權未明字型或執行資料。
- [ ] PulseVeto Overlay 若不在授權範圍，維持原樣。

