# 排版與字體規則

## 字型

來源特徵：非 Overlay 介面採 Inter、Segoe UI、Noto Sans TC 與系統無襯線字型。新專案可用下列字型堆疊；列出名稱不代表已下載或允許再散布。

```css
:root {
  --font-ui: Inter, "Segoe UI", "Noto Sans TC", "Noto Sans SC",
    "Noto Sans JP", system-ui, sans-serif;
  --font-code: ui-monospace, Consolas, monospace;
}
body { font-family: var(--font-ui); }
button, input, select, textarea { font: inherit; }
```

預設使用系統 fallback 即可；載入外部字型前確認授權、效能與所需語系。品牌展示字型只用在少量標題。代碼、UID 與機器資料可用等寬字型；一般中文正文維持 UI 字型。

## 字級尺度：新專案建議預設

以下以根字級 16px 為參考，實作用 `rem`，不覆寫使用者字級設定。

| 角色 | 桌面 | 手機 | 行高 | 字重 |
| --- | --- | --- | --- | --- |
| 品牌展示標題 | 40–56px | 32–40px | 1.15–1.25 | 700–800 |
| 頁面 H1 | 32–40px | 28–32px | 1.25 | 700 |
| 區塊 H2 | 24px | 22px | 1.35 | 700 |
| 分組 H3 | 18–20px | 18px | 1.4 | 600–700 |
| 正文／輸入 | 16px | 16px | 1.6–1.75 | 400–500 |
| 按鈕／欄位標籤 | 14–16px | 14–16px | 1.4–1.5 | 600 |
| 輔助說明／表格 | 14px | 14px | 1.5–1.65 | 400–500 |
| 非關鍵註記 | 12px | 12px | 1.5 | 400–500 |

既有頁面含更小的裝飾字與註記；新專案不沿用這些作為必要資訊的尺寸。若資料密集，先減少低價值欄位與調整布局，不持續縮小字體。

## 層級與可讀性

- 每個頁面的主要內容有一個清楚 H1，依內容使用 H2／H3；不以字級大小代替標題語意。
- 正文與管理資訊預設靠左；登入標頭、結果數值或簡短空狀態可置中。
- 長文閱讀區建議最大寬度 42rem，依中文內容實測；資料列表可使用較寬容器。
- 中文不強制增加字距。英文展示標題可微調字距，不能使中英混排過度擠壓。
- 主標與正文以字級、字重及間距建立層級；同一區塊避免同時使用過多字重與強調色。
- 數值欄位使用 `font-variant-numeric: tabular-nums`，金額與比分對齊；不要為一般正文啟用固定寬數字。

## 中英混排與長文字

- 中文句子使用全形中文標點；技術識別符、版本、URL 保留原格式。
- 可寫「建立 BP」「支援 OBS」等自然混排，不在資料原值中插入格式空格。
- 名稱可換行；短列表允許省略，但提供可存取的完整內容。不能省略金額、操作結果或關鍵警告。
- 長 URL／UID 區域可用 `overflow-wrap: anywhere`；不對所有正文套 `word-break: break-all`。
- 不靠固定高度或手動換行維持文案版型；以最長語系與 200% 縮放驗證。
- 圖像內文字只限必要品牌素材，操作、標題與說明保留真實文字。
