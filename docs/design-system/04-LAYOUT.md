# 版面、間距與響應式

本文件的統一尺寸為新專案建議預設。PulseVeto 既有頁面使用不同斷點與容器，不能據此宣稱它們已符合此尺度。

## 間距尺度

採 4px 基準：4、8、12、16、24、32、48、64。以間距表示關係，相關內容靠近，不同任務留出更大的距離。

| 場景 | 建議間距 |
| --- | --- |
| 圖示與文字 | 8px |
| 標籤與欄位／正文與說明 | 8px |
| 同組控制項 | 12–16px |
| 卡片／表單內距 | 手機 16px、桌面 24px |
| 相鄰分組 | 24–32px |
| 主要頁面區塊 | 32–48px |
| 品牌展示段落 | 48–64px |

## 容器與網格

- 一般工作區最大寬度 1320px、長文 42rem、單一登入表單 28rem。
- 手機頁面左右內距 16px，平板 24px，桌面 32px；滿版工具可另定需求。
- 桌面側欄建議 240–256px，內容欄使用 `minmax(0, 1fr)`，避免長文字撐開網格。
- 主要表單優先單欄；只有同一概念的成對欄位才在空間足夠時並排。
- 卡片網格依內容決定最小寬度，資訊列表優先行式排列。不要為填滿空間新增指標卡片。

```css
.page-shell {
  width: 100%;
  max-width: 1320px;
  margin-inline: auto;
  padding-inline: 16px;
  box-sizing: border-box;
}
.workspace { display: grid; gap: 24px; }
.workspace > * { min-width: 0; }
@media (min-width: 768px) {
  .page-shell { padding-inline: 24px; }
}
@media (min-width: 1024px) {
  .page-shell { padding-inline: 32px; }
  .workspace { grid-template-columns: 252px minmax(0, 1fr); }
}
```

## 響應式策略

建議以 768px、1024px 為起始斷點，內容開始擠壓時即可調整，不依裝置品牌判斷。手機改單欄、按鈕列允許換行；桌面側欄在小螢幕改為可開關導覽。

- 最小驗收寬度 320px，常用手機 390px、小型筆電 1366×768、大螢幕 1920×1080。
- 小型筆電首屏應看得到頁面目的與主要操作，品牌展示不能將所有操作擠到首屏外。
- 頁面避免水平捲動；大型資料表可在具明確標示的局部容器捲動，保留必要欄位與可操作性。
- 固定頁首或底部操作列不可遮住焦點、最後一列資料及錯誤訊息。
- 彈出層最大高度受視窗限制，內容可捲動；手機鍵盤開啟時仍能看見目前欄位與提交結果。

## 資訊結構

依使用者任務分組：導覽 → 頁面名稱與說明 → 必要資訊 → 主要動作 → 次要細節。統計必須有用途與時間範圍；文件入口與操作入口可獨立分組。

PulseVeto 專屬：全域「賽事單位」保持頂層，不藏在「賽事」之下；比分、BP 與文件依任務組織。一般專案重新定義自己的層級，避免直接搬用賽事名詞。
