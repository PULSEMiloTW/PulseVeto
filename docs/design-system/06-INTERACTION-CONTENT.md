# 互動、動效與內容

## 動效預設

以操作關係與狀態回饋為目的。既有介面常用短轉場；新專案建議微互動 150–200ms、對話框進出 180–250ms，只動畫 `opacity` 與 `transform` 等不影響版面排列的屬性。

- Hover 最多小幅位移，資料列表不反覆浮動。
- 品牌區可採少量裝飾動畫；操作區避免持續旋轉、閃爍與無意義呼吸效果。
- 使用 `prefers-reduced-motion: reduce` 停用非必要動效；保留載入狀態的文字提示。
- 主題切換不得改變內容尺寸。即時資料更新維持使用者位置，不整頁重繪造成焦點遺失。
- 使用 CSS 可以完成的簡單轉場優先用 CSS；不為這套規範新增動畫依賴。

## 操作回饋

點擊後立即顯示處理狀態；成功說明完成的動作，失敗提供可行的下一步。連線中斷與資料過期使用清楚狀態，不能顯示成已成功儲存。

即時倒數只在低於 10 秒時加強警示，不能每秒透過讀屏公告。PulseVeto 超時訊息不阻塞流程，隨後自動更新結果；隨機結果確認與 BP 規則仍由產品與伺服器實作決定。

## 文案語氣

繁體中文為預設，直接說明目的與結果。避免裝飾性英文、內部技術名詞與誇大承諾。

| 情境 | 建議文案 |
| --- | --- |
| 操作 | 儲存設定／建立專案／複製連結 |
| 空白 | 尚無專案。建立第一個專案以開始使用。 |
| 成功 | 設定已儲存。 |
| 失敗 | 無法儲存設定，請稍後再試。 |
| 欄位錯誤 | 請輸入專案名稱。 |
| 未確認狀態 | 尚未取得狀態，請重新整理。 |

錯誤訊息不洩漏秘密或未授權資源；若可安全指出欄位問題，提供具體原因，不只顯示「錯誤」。

## 多語系與主題

PulseVeto 沿用 `zh-TW`、`zh-CN`、`en-US`、`ja-JP`；新專案在設定表確認需要的語系，不要求無需求的產品全部翻譯。

- 翻譯涵蓋標題、控制項、錯誤、空狀態、對話框與可存取名稱，不只翻譯導覽。
- 更新文件的 `lang`，避免串接碎片句子；日期與數值依語系格式化。
- 術語建立對照表，使用者輸入的名稱不當成翻譯鍵。
- 語言切換保留目前操作內容，按鈕允許較長翻譯，不靠固定寬度截斷。
- 新專案建議首次依系統主題，之後遵循使用者選擇；若產品明確指定初始主題則記錄例外。
- 使用同一狀態語意覆蓋明暗主題，不因主題改變成功／危險的含義。

PulseVeto 術語延伸：賽事單位／賽事／單場 BP／隊伍代碼／最近刪除；一般專案改為自己的領域詞彙。
