# 本地主題封閉測試

於專案根目錄執行 `node --import tsx scripts/closed-beta.mjs`，或雙擊 `scripts/start-closed-beta.cmd`。預設入口為 <http://127.0.0.1:3180/__beta>；只監聽本機回環介面。可透過 `CLOSED_BETA_PORT` 使用其他連接埠，禁止使用 3000、3100、3110。

本版透過獨立樣式層預覽首頁、管理、隊伍、賽果與其他既有頁面。頁首可切換新版／原版，以及明暗配色；原有四語言、管理階層、資料表單與 BP 規則保留。Overlay 路徑不注入新主題。動效使用原生 CSS 的 transform／opacity，並遵循 reduced-motion；沒有新增前端框架或依賴。

啟動器只使用 `output/closed-beta-runtime/storage/database/closed-beta.db`，對此測試資料庫執行現有 migration。帳號、金鑰、日誌、上傳、文件編輯與備份保存在獨立測試目錄；不載入根目錄 `.env`、不複製正式資料、不啟動 Tunnel。不要將此目錄提交或公開。測試管理員按鈕經由原有登入與 CSRF 流程，並非略過授權。

首次啟動建立 Bo1／Bo3／Bo5 對局與測試地圖；優先使用本地公開地圖目錄快取，無快取時使用七張示範地圖與品牌圖片占位。此地圖池僅供測試，並非官方當季輪替。資料與測試金鑰保留至下次啟動；初始金鑰有效 30 天，過期後從測試管理頁重新簽發。使用不同瀏覽器或獨立瀏覽器設定檔登入雙方，避免共用隊伍 Cookie。

Discord OAuth 在此環境停用；HQ 保留既有授權入口，但不啟動獨立 HQ 服務。狀態頁呈現測試環境自身資訊，沒有啟動正式監控排程。此環境適合主題、管理及 BP 操作測試，不能代表正式環境、OAuth、HQ、網路或 OBS 接收已驗證。

結束測試請在測試主控台按 Ctrl+C。如需全新測試資料，先停止本測試程序，再自行移除 `output/closed-beta-runtime` 後重新啟動。勿操作其他資料庫或服務。

主題尚未掛載於正式頁面；本機預覽讀取目前工作目錄，包括尚未提交的既有頁面。Git 交付僅包含新主題資產與測試啟動工具，既有未提交工作仍由原工作目錄保留。
